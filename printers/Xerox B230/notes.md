# Xerox B230 research notes (saved as I go)

## Official datasheets (office.xerox.com)
- https://office.xerox.com/latest/B23BR-01E.PDF (English, Europe): B230 H x W x D = 232 x 355 x 333 mm, 6.8 kg.
  Up to 34 ppm A4 (marketing). 250-sheet tray, 1-sheet manual feed slot, 150-sheet face-down output.
  USB 2.0 type B, Ethernet 10/100, Wi-Fi 802.11 b/g/n, Wi-Fi Direct (mobile printing list).
  Toner 006R04399 (1,200), 006R04400 (3,000), 006R04401 (6,000); imaging kit (drum) 013R00691 ~12,000 pages.
  In the box: product, pre-installed starter cartridge 1,200 pages, Software & Documentation CD, installation guide + safety sheet,
  quick use guide, power cord.
- https://office.xerox.com/latest/B23BR-01W.PDF (Swedish): same dims 232 x 355 x 333 mm = 9.1 x 14.0 x 13.1 in, 6.8 kg / 15 lb.
  ISO/IEC 24734 speed: 31 ppm Letter / 30 ppm A4.

## User guide (https://www.adorama.com/col/productManuals/XEB230DNI.pdf)
- p.18 configuration: control panel, power button, manual feeder, 250-sheet tray, standard output tray.
- p.19 control panel: display, indicator light, Home, left/right arrows, Back, Stop/Cancel, Menu, Select.
- p.28-29 clearances: top 120, rear 260, right 120, front 550 (min 76), left 120 mm (ventilation).
- p.30 ports, in this order: Ethernet port, USB printer port, power cord socket.
- p.164-169 jams: output tray, front door, manual feeder, tray, REAR DOOR (+ fuser access door), DUPLEX UNIT ("pull out the duplex unit").

## Chassis: Lexmark B2236dw (same W, D, weight) https://www.lexmark.com/en_gb/printer/14204/Lexmark-B2236dw
- 215 x 355 x 333 mm (H x W x D), 6.8 kg, 2-line LCD, 150-sheet bin, single-sheet manual feed, imaging unit 12k, starter 700.
- Xerox datasheets say H = 232 mm (17 mm taller). To check from photos: front H/W = 0.654 (232) vs 0.606 (215).

## Official dimension graphic (Xerox product page)
- https://www.office.xerox.com/assets/images/brand_engine/products/hardware/B230/xerox-B230-Dimensions_800x450.jpg
  on https://www.xerox.com/en-us/office/printers/xerox-b230-printer : H 8.5 in / 216 mm, W 14 in / 356 mm, D 13.1 in / 333 mm, 15.0 lb / 6.8 kg.

- Look: white body, dark navy top cover, recessed top output bin with stop, small 2-line LCD + buttons top right,
  power button front right, manual-feed cover below logo, 250-sheet cassette with vertical paper gauge window (front right), vents on right side.
